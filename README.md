# StudentIn - Academic Mentorship Platform
This repository contains the **MVP (Minimum Viable Product)** implementation and technical documentation for the StudentIn platform. It showcases the transition from high-fidelity Figma designs into functional code components.

## Technical Implementation
- **Framework**: Developed using **React** with **Vite**.
- **Languages**: TypeScript (TSX) and CSS for styling.
- **Key Logic**: Includes project configurations (`package.json`, `vite.config.ts`) and core application routing (`App.tsx`).

## System Architecture & Pages
The repository includes the source code for the following core modules:
1. **User Authentication**: Login interface implementation.
2. **Student Profile**: Layout for displaying skills, progress, and personal information.
3. **Mentorship Bridge**: UI components for connecting users with academic mentors.
4. **Project Hub**: Task management system with progress tracking.

## Design Assets
- **Documentation**: Comprehensive design reference and UI/UX wireframes.
- **Assets**: Image files and icons used within the application interfaces.
